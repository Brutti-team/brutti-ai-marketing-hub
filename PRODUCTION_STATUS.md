# BRUTTI AI Marketing Hub — Production Status

Updated 20 August 2026.

The current production frontend includes the dynamic weekly planner and Daily Focus, live-ready product source workflow, Drive visual attachment, improved Free Smart Rewrite variation controls, operational analytics, and review-first Facebook publishing UI.

The frontend is also configured as an installable phone/tablet PWA with local app icons, an in-app install control, mobile bottom navigation, safe-area spacing, an offline fallback screen and direct app shortcuts to Content Studio, Campaign Planner and Asset Library.

The repository backend also includes optional Notion product/planner sync and Facebook photo publishing through Google Apps Script. These backend integrations only become active after the updated Apps Script source is deployed and the required private Script Properties are configured.
